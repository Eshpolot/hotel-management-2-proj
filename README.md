# Hotel Management System

Проект на C# Windows Forms (.NET Framework 4.7.2).
Тема: система управления гостиницей.

## Сделано — 20%

- Form1 — главная форма, кнопки перехода: Гости, Номера, Бронирование, Выход
- Form2 — гости: ФИО, телефон, паспорт. Добавление и удаление в DataGridView
- Form3 — номера гостиницы: номер, тип, цена за ночь, статус. Добавление и удаление
- Form4 — бронирование: гость, номер комнаты, дата заезда и выезда, подсчёт количества ночей

Пока данные хранятся только в таблицах на формах и не сохраняются после закрытия программы.

## Как открыть

Открыть файл `hotel management 2 proj.slnx` в Visual Studio, запустить кнопкой F5.
Формы открываются в конструкторе двойным щелчком по файлу формы в обозревателе решений.
